# Austonix AI Trader – Clickable MVP Prototype

**Phase 1 Foundation Prototype**  
Educational + Paper-Trading platform concept  
Product Owner: Austonix Golden Heirs Ltd

## How to Open the Clickable Prototype

### Option 1 – GitHub Pages (recommended)
1. Go to the repository: https://github.com/Austonix/austonix-ai-trader-mvp
2. Settings → Pages → Source: Deploy from a branch → Branch: `main` → Folder: `/ (root)` → Save
3. After 1–2 minutes the live URL will be:  
   **https://austonix.github.io/austonix-ai-trader-mvp/**

### Option 2 – Open directly
- Download `index.html` and open it in Safari / Chrome on your iPhone.
- Or use a service that serves raw GitHub HTML.

## What You Can Click & Use Right Now

| Screen | Features |
|--------|----------|
| **Home** | Paper equity card, live-mock watchlist, open positions, quick actions, risk principle tip |
| **Markets** | Pair selector, mock candlestick chart, RSI/MACD/MA/ATR cards, timeframe buttons |
| **AI** | Full chat interface with educational responses, uncertainty language, disclaimers, quick prompts |
| **Trade** | Working position-size calculator (equity, risk %, entry, stop → suggested size) + open/close paper trades |
| **Journal** | Closed trades history, win rate, net P&L, quick journal notes |
| **Profile** | Demo user info + reset all data |

All paper trades and journal entries persist in the browser (localStorage).

## Design Principles Shown

- Risk before profit (calculator is forced before trading)
- Intelligence before automation
- Transparency before promises (AI always shows uncertainty + disclaimer)
- Education alongside technology
- Paper-trading only – no live execution, no real money
